📌 Project Overview

Recipe Blog is a web-based application developed to provide users with a collection of delicious recipes. Users can explore different dishes, view ingredients, and follow step-by-step cooking instructions.

✨ Project Features
Browse different food recipes
View recipe ingredients
Read step-by-step cooking instructions
Explore various dishes
User-friendly web interface

Start Apache and MySQL.
Copy the Recipe Blog project folder into C:\xampp\htdocs\.
Create the required database.
Import the project's SQL file into the database.
